Sobre Nosotros

echo "##active_line29##"

NEXUS es un laboratorio de herramientas web autoalojadas. Cada módulo resuelve un problema concreto con el mínimo código necesario.

echo "##active_line30##"
echo "##active_line31##"

Misión

Construir utilidades web funcionales, sin dependencias externas, servidas desde un único VPS Linux. Prioridad: rendimiento, simplicidad y autoalojamiento total.

Autoalojado · PHP + SQLite
echo "##active_line32##"

Filosofía

Cero frameworks pesados. HTML+CSS+JS vanilla en el frontend, PHP procedural con PDO/SQLite en el backend. Cada módulo es independiente y portable.

Vanilla JS · Sin build step
echo "##active_line33##"

Tecnología

Ubuntu Linux 24.04 · Apache/Nginx · PHP 8.4 · SQLite · FFmpeg (multimedia) · Git + GitHub Actions para despliegue.

Stack ligero
echo "##active_line34##"

Módulos Activos

Chat de Sesiones · Editor Multimedia · CounterKCal · Panel Inglés · Acerca/Info. Cada uno con su propia BD SQLite y API REST interna.

5 módulos en producción
echo "##active_line35##"

Principios

Código legible > código corto. Idempotencia en scripts de despliegue. Sin cookies, sin tracking, sin analytics. Privacidad por diseño.

Privacy-first
echo "##active_line36##"

Roadmap

Próximos: modo multi-usuario con tokens, exportación de sesiones a Markdown/PDF, integración con WebDAV para sincronización entre equipos.

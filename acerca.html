🚀 Misión & Filosofía

NEXUS es un portal modular autoalojado en Linux donde cada sección funciona de forma independiente. El objetivo es construir herramientas web funcionales (no maquetas) con persistencia real, optimización de rendimiento y control de versiones.

  • Autoalojamiento: Todo corre sobre un único servidor Ubuntu sin dependencias externas.
  • Persistencia: Cada módulo que requiere datos usa SQLite (cero overhead, archivo local).
  • Optimización: HTML semántico, CSS inline mínimo, cero frameworks externos, lazy-load implícito por estructura.
  • Versión controlada: Repo Git sincronizado con GitHub; commits atómicos por funcionalidad.
